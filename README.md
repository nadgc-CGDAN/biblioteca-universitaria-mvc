# biblioteca-universitaria-mvc
A **Biblioteca Universitária** é um sistema de gestão desenvolvido em **Python** utilizando o padrão arquitetural **MVC (Model-View-Controller)** e integrado ao banco de dados **PostgreSQL**. 

O objetivo principal do projeto é aplicar na prática os pilares da **Orientação a Objetos** (Encapsulamento, Abstração e Separação de Responsabilidades), permitindo o gerenciamento completo (CRUD) de **Autores** e **Livros**, com suporte a consultas com `JOIN` e integridade referencial com `ON DELETE CASCADE`.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 
* **Banco de Dados:** PostgreSQL 16
* **Driver de Conexão:** `psycopg2`
* **Arquitetura:** MVC (Model-View-Controller)
* **IDE/Ferramentas:** VS Code, pgAdmin 4
